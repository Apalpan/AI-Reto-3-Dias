# AI Reto 3 Días AECODE

Micrositio estático para operar la guía del Reto 3 Días AECODE.

## Contenido

- `index.html`: guía interactiva completa.
- `assets/aecode-logo-principal-fondo-blanco.png`: logo oficial AECODE para fondo blanco.
- `.nojekyll`: evita procesamiento innecesario en GitHub Pages.

## Funciones principales

- Hero con logo oficial AECODE y narrativa de Sesión 1.
- Pestañas para Sesión 1, Sesión 2 y Sesión 3.
- Agenda por minutos con filtros por responsable.
- Panel operativo del bloque seleccionado.
- Botón de copia para prompt base.
- Barra de progreso, scroll reveal, microinteracciones y modo impresión/PDF.
- Responsive sin scroll horizontal en desktop ni móvil.

## Verificación local

Abrir `index.html` directamente en el navegador.

Validado en:

- Desktop: 1440 x 1100
- Mobile: 390 x 950
